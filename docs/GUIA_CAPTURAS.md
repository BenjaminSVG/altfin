# Guía de capturas de referencia

Guarda las imágenes en `referencias/capturas/ (carpeta local, no se versiona)<app>/NN-descripcion.png`. Uso: moodboard interno, no se redistribuyen.

| App | Pantallas a capturar | Qué observar |
|---|---|---|
| YNAB | Presupuesto (categorías con barras), onboarding | Cómo explica "dale un trabajo a cada peso"; colores de estado |
| Monarch Money | Dashboard, presupuesto flex, patrimonio, resumen semanal | Jerarquía visual, número principal, gráficas |
| Duolingo | Inicio con racha, pantalla de lección completada, notificaciones, ligas, tienda | Mascota, celebraciones, copy de recordatorios, racha |
| Finch | Mascota principal, check-in diario | Cómo crece la mascota según hábitos |
| Fintonic / Goodbudget | Categorías, sobres | Registro de gastos y categorización |
| Wallet by BudgetBakers / Spendee | Añadir gasto rápido | Cantidad de toques para registrar |
| Apps de inversión (Robinhood, Fintual, etc.) | Gráfica de crecimiento, metas | Visualización de crecimiento y simuladores |

## Qué anotar por captura
1. Qué hace bien. 2. Qué evitar. 3. Colores/tipografía. 4. Elemento de gamificación. 5. Idea para Capi.

## Dónde capturar
Fichas oficiales de Google Play / App Store (capturas promocionales) o capturas propias de las apps instaladas.
