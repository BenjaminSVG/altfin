Cómo instalar

Listo en un minuto.

Android

  1. Descargá el archivo arm64-v8a (casi todos los celulares nuevos). Si no abre, probá con armeabi-v7a.
  2. Abrilo. Android te pide permitir instalar apps de este origen: aceptá.
  3. Abrí AltFin y permití las notificaciones si querés recordatorios.

Va firmada con una clave de prueba: para pasar a una versión nueva hay que desinstalar la anterior. Hacé antes la copia de seguridad en Ajustes.

Windows

  1. Descargá el ZIP y descomprimilo en una carpeta.
  2. Abrí altfin.exe. No necesita instalador.
  3. Si falta una DLL, instalá el Visual C++ Redistributable.

Windows puede avisar que el editor es desconocido: la app es libre y su código está abierto.
